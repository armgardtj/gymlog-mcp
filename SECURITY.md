# Security

GymLog's MCP server is hosted by GymLog. This repository holds documentation only, with no code to patch.

## Reporting a problem

If you find a security problem with the hosted server at `https://getgymlog.web.app/mcp`, the sign-in flow, or the
GymLog apps, email us with "Security" in the subject. The address is in the
[privacy policy](https://getgymlog.web.app/privacy.html) (Section 12, Contact). Please include the steps to reproduce
it and, if you can, what an attacker could do with it.

- Please don't open a public issue for a security problem, and don't test against other people's accounts or data.
- You'll get a reply within 7 days. Fixes ship on the hosted server, so there's nothing for you to update.
